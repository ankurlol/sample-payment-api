# Sample Payment API (Standalone Service)

A lightweight standalone Python service with GitHub Actions CI/CD to test automated rollbacks with the **Self-Healing SRE Copilot**.

## Quick Push to GitHub

```bash
git init
git add .
git commit -m "v1.0.0: Initial stable release"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/sample-payment-api.git
git push -u origin main
```
